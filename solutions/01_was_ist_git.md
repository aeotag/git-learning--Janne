# ============================================================
# ✅ Lösungen zu Lektion 1: Was ist Git?
# ============================================================


## ────────────────────────────────────────────────────────────
## Lösung 1.1:
## ────────────────────────────────────────────────────────────

```
Dein Befehl:
git --version

Dein Ergebnis:
git version 2.39.0   (oder eine andere Versionsnummer)
```


## ────────────────────────────────────────────────────────────
## Lösung 1.2:
## ────────────────────────────────────────────────────────────

```
Git ist ein Programm, das auf deinem Computer läuft und Änderungen
an Dateien verfolgt. GitHub ist eine Webseite im Internet, auf der
du deine Git-Projekte online speichern und mit anderen teilen kannst.
Git ist das Werkzeug, GitHub ist der Online-Speicher.
```


## ────────────────────────────────────────────────────────────
## Lösung 1.3:
## ────────────────────────────────────────────────────────────

```
Befehl 1 (Name):
git config --global user.name "Janne"

Befehl 2 (E-Mail):
git config --global user.email "janne@example.de"

Befehl zum Prüfen:
git config --list
```


## ────────────────────────────────────────────────────────────
## Lösung 1.4:
## ────────────────────────────────────────────────────────────

```
Repository  → 2  (Ein Projektordner, den Git überwacht)
Commit      → 4  (Eine gespeicherte Änderung)
Branch      → 5  (Ein Zweig – eigene Kopie zum Arbeiten)
Push        → 3  (Änderungen auf GitHub hochladen)
Pull        → 1  (Änderungen von GitHub herunterladen)
```
